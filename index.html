AI 使用規則

AI 可以加速，但不能替你把核心能力挖空。

JS 基礎先自行拆題並嘗試，卡住先要提示；看過解法後關掉重寫，隔天再驗收。Teaching Material Builder 帶學，Production Debugger 協助定位問題。
DOM / API事件、fetch 與資料處理先自己寫；AI 幫忙 review。進入 API 單元就使用 API Integration Planner，不用等月份。
PHP / LaravelAI 可協助樣板，但要自己解釋請求、驗證、資料庫與回應；SQL 與權限判斷必須能修改。
