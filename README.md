# Ray Learning OS

26 週全端學習與成果追蹤系統。期間：**2026/10/06 ～ 2027/04/02**。

## 核心原則
這個 Repository 不只放課表，也要留下 **每週實作成果**。半年後可以直接回頭看自己從 JavaScript 基礎、API、PHP/MySQL、Laravel 到 Full Stack 專案的成長軌跡。

## Repository 結構

```text
ray-learning-os/
├─ index.html                 # 學習 Dashboard
├─ learning/
│  ├─ README.md               # 26 週成果索引
│  ├─ week01/
│  │  └─ README.md
│  ├─ week02/
│  └─ ... week26/
├─ final-project/             # 最終自選 Full Stack 專案
└─ README.md
```

## 每週最低交付標準
1. 至少一份練習或小功能
2. 本週 README 紀錄
3. 至少一次自己 Debug 的紀錄
4. 週五測驗結果
5. Git commit + push

## Commit 建議
```text
practice: finish week02 loop exercises
feat: add week05 todo app
fix: correct week07 async error handling
docs: update week10 learning notes
```

## 學習成果
每週成果放在 `learning/weekXX/`。網站中的「學習成果」頁會直接連到各週資料夾。

## AI 使用原則
AI 可以協助講解、提示、除錯與 review，但核心能力要能自己修改、解釋與 debug。10–11 月核心 JavaScript 練習，先自己做 20 分鐘再問 AI。
